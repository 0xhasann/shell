## Reporting a Vulnerability
If you find a security issue, DO NOT open a public issue.

Instead:
DM: [@yourhandle](https://x.com/hsn_dev_)

Please include:
- Description of the issue
- Steps to reproduce
- Possible impact

We will respond within 48 hours.
